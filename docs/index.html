Runs all 80 trials for the current network size in your browser and compares them with the verified MATLAB averages.

The browser engine ports the MATLAB model: Gaussian-beam optics, sliding-mode pointing control, the fault injector, both supervisors, Dijkstra rerouting and the original metric definitions. It integrates with fixed-step RK4 and uses its own random generator, so its numbers come close to the MATLAB batch without matching it exactly. The MATLAB results page holds the verified figures.
