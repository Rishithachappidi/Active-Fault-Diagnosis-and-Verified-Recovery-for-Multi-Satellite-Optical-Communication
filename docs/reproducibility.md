# Reproduce the platform

## Zero-dependency application and experiments

Node.js ≥20.11 (tested Node 24.17). No npm installation is required for the application, engine or numerical tests.

```sh
npm start
# open http://127.0.0.1:4173
npm test
npm run verify:baseline
npm run experiments
```

A local HTTP server is necessary for browser ES modules and workers. Double-clicking index.html as file:// is unsupported. The server binds to loopback only. Static hosting works because all computation is client-side; no deployment was performed.

The experiment runner writes optimization, eight matched missions, ablation, 100 paired environments, step sensitivity and demo data. Original strict baseline results are regenerated by `node scripts/baseline-runs.mjs`. Seeds and full resolved configs are in JSON. Metrics are deterministic; rendering timestamps and screenshots are not numerical fixtures.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-plots.txt
.venv/bin/python scripts/plot_results.py
node scripts/report-results.mjs
```

The plot script produces PNG and editable SVG scientific figures. The browser exports per-run JSON, per-spacecraft downsampled CSV, current plot PNG and a printable report with parameters, faults, metrics, plots and available optimizer/campaign summaries. Use the report's Print / save as PDF button for PDF output. No PDF engine is required.

## MATLAB / Simulink

```matlab
cd simulation
R = sff_run_all; % original workflow
addpath extensions
sff_validate_baseline % original MATLAB functions vs frozen JS fixture
C = sff_twin_config;
C.faults(1,:) = [2 20 10 2 0.8 0.45 0.8 4];
R = sff_twin_run(4,C); % proposed adaptive, independent native RK4
Rself = sff_twin_run(5,C);
mdl = sff_build_twin_model(C); % creates NEW sff_twin_model
sim(mdl);
```

Original functions have hard-coded constants; changing sff_params alone is not a supported baseline experiment. Extension config is separate. The extension builder supports modes 4/5; use the original model for cases 1/2/3. Original MATLAB/SLX execution, native extension code generation and numerical parity require local verification; no successful execution is claimed here.

## Browser regression

Install Playwright separately if desired (`npm install --no-save playwright@1.62.1`, then `npx playwright install chromium`) and run `node scripts/ui-check.cjs` while npm start is running. `PLAYWRIGHT_MODULE` may point to an existing Playwright module installation. The test checks console errors, replay, selection, mobile overflow and saved campaign/comparison rendering. More workflow tests are in `scripts/ui-workflows.cjs`.

## Result provenance

`baseline/manifest.json` protects original files. `baseline/regression.json` protects the new port. `results/provenance.json` records engine/research source hashes with generation time and environment. It is not an independent scientific validation. `docs/RESULTS.md` and plot files are generated from results, never manually improved.
