# Experiment matrix and fair comparisons

Run `npm run experiments`. Outputs are local JSON files under results; original output_images are not overwritten.

| Experiment | Scenario | Conditions |
|---|---|---|
| E1 | nominal | healthy actuators |
| E2 | degradation | SC2 gradual partial loss |
| E3 | failure | SC2 X-axis zero authority |
| E4 | multiple | SC2 + SC3 losses |
| E5 | dropout | 35% loss after 20 s |
| E6 | disturbance | eightfold disturbance after 20 s |
| E7 | noise | sigma 0.0001 MRP and rad/s |
| E8 | combined | SC2 severe loss + 20% loss + 3× disturbance |
| E9 | paired Monte Carlo | 100 environments × 5 policies |
| E10 | ablation | A–F under identical combined mission |

E1–E8 each compare six policies, including fault-aware self. All use seed 42, dt=0.01, T=60 s, budget=500. Training uses different randomized seeds. Strict baseline outputs use dt=0.001 and original effectiveness, no mission modifications. Never juxtapose their RMSE as if they shared healthy mission conditions.

Ablation: A baseline event; B adaptive scheduling only; C adds estimated severity and residual disturbance features; D adds communication-pressure terms; E adds tuned parameters; F adds bounded effectiveness compensation. The broadcast cap is enforced in every condition; D specifically adds pressure-aware scheduling. B also introduces max-hold refresh and chi clamping, so it is a scheduler-package ablation, not an isolated single-coefficient causal estimate. C combines diagnosis features; separate disturbance-versus-severity effects remain future work.

All attempts count toward the same budget, including lost packets. Time-driven policies keep local control active after the channel cap. Current-sample periodic neighbor data are used when delivered; unavailable neighbors retain last delivered state. Event/self modes read snapshots to avoid spacecraft loop-order dependence.

`results/step-refinement.json` provides dt sensitivity for three methods. Static scientific PNG and SVG figures are generated by `scripts/plot_results.py`. UI plots are sourced from the same exported simulation histories, but are downsampled; full-rate costs are accumulated separately.
